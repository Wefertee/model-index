# Model Index

Одностраничный справочник-сравнение моделей ИИ: 7 лабораторий, 13 моделей, 10 метрик.
Один файл `index.html` (HTML + CSS + JS, без сборки) плюс маленький сервер для формы обратной связи.

## Запуск

Сайт работает и как обычный файл — достаточно открыть `index.html` двойным кликом.
Форма обратной связи требует сервера:

```bash
node server.js
# Model Index: http://127.0.0.1:8123  ·  хранилище: .../feedback.db
```

Порт меняется переменной окружения: `PORT=3000 node server.js`.
Node 22.5+ — используется встроенный `node:sqlite`, зависимостей нет.

## Обратная связь

Кнопка «форма обратной связи» в футере открывает модальное окно (`<dialog>`).

`POST /api/feedback` — тело `{name?, email, message}`:

- e-mail проверяется регуляркой, сообщение 4…4000 символов, тело ≤ 32 КБ;
- антиспам: не чаще одного сообщения в 15 секунд с одного IP + скрытое поле-ловушка `company`;
- ответ: `{"ok":true,"id":12}` либо `{"error":"..."}` с кодом 400/413/429/500.

`GET /api/feedback` — последние 50 сообщений в JSON, только с этой машины (127.0.0.1).

## Где лежат сообщения

`feedback.db` — SQLite, таблица:

```sql
CREATE TABLE feedback (
  id, created_at, name, email, message, ip, ua
);
```

Посмотреть содержимое без установки чего-либо:

```bash
node -e "const{DatabaseSync}=require('node:sqlite');const d=new DatabaseSync('feedback.db');console.table(d.prepare('select id,created_at,email,substr(message,1,60) m from feedback order by id desc').all())"
```

Если `node:sqlite` недоступен (старый Node), сервер автоматически пишет в `feedback.jsonl` — по объекту на строку.

## Файлы

| файл | что это |
|---|---|
| `index.html` | весь сайт: данные моделей в массиве `MODELS`, стили, роутинг, форма |
| `server.js` | статика + `/api/feedback`, без зависимостей |
| `feedback.db` | база сообщений (создаётся при первом запуске) |

## Правки данных

Оценки — в массиве `MODELS` в начале `<script>` в `index.html`; всё остальное (таблицы, радар, выводы, сортировка) считается из него.
Приблизительные значения помечены `≈` и обесцвечены; происхождение — в разделе «Методология».
